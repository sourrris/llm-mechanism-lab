# Contributing to your own understanding

A contribution is accepted when it increases causal clarity.

Good commits contain one coherent unit:

- `day 03: implement causal attention and falsify attention-as-explanation`
- `day 06: trace exploding loss to missing gradient zeroing`
- `day 10: localize IOI restoration with negative control`

Avoid commits named `progress`, `update`, `stuff` or `AI generated solution`.

Never remove failed predictions from history. Correct them explicitly.
