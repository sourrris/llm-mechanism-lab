# Evidence standard

Use this ladder for every mechanism claim.

1. **Observation:** the behaviour occurred under a fully specified setup.
2. **Association:** an activation or component covaries with the behaviour.
3. **Localization:** the relevant information/effect is concentrated in a layer, position or component.
4. **Intervention:** changing that internal variable changes the target metric as predicted.
5. **Mechanism:** a component-level causal model predicts multiple counterfactual interventions.
6. **Generalization:** the explanation survives held-out prompts, seeds, checkpoints or models.

Do not label levels 1–3 a complete mechanism.

Every serious note separates:

- **Known:** directly measured or mathematically established.
- **Inferred:** best explanation supported by evidence but not directly observed.
- **Speculative:** plausible hypothesis awaiting a discriminating test.
- **Unknown:** not resolved by available access or experiments.

For agency language, separate:

- **Observable behaviour:** tokens or actions produced.
- **External instruction:** system, user, retrieval and tool input.
- **Functional objective:** prediction/reward structure shaping output.
- **Personal intent:** not established by fluent first-person text.
