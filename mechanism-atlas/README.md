# Mechanism atlas

The atlas is not a glossary. Every entry must contain:

1. Inputs and outputs.
2. Equation or algorithm.
3. Tensor shapes.
4. Computational role.
5. One predicted intervention.
6. One common false explanation.
7. Evidence level.
8. Remaining unknowns.

Create entries as you pass days. Day 14 consolidates them into `final-atlas.md`.
